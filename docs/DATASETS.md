# Dataset cards and provenance

| Dataset | Size | Judgment scope | Role |
| --- | --- | --- | --- |
| Public company pilot | 130 records, 38 queries | 215 pooled judgments; unknown pairs remain unknown | Source-backed development checks |
| Controlled company screening | 2,400 records, 120 queries | 1,920 explicit rel labels; all other pairs negative by synthetic construction | Repeatable rank and exclusion regression |
| Long-context adversarial | 56 records, 7 queries | Explicit positive, excluded and unknown cases | Truncation, negation and scope diagnostics |
| BEIR SciFact test | 5,183 documents, 300 queries | Official test qrels, unjudged pairs unknown | Public-domain transfer check |

The public pilot is adapted from the previous [Company Embedding Benchmark](https://github.com/saksham-personal/company-embedding-benchmark) curation. It contains independently written factual summaries, official source references, rationales and hard negatives. The original bundle is retained in `data/public-source-original/`; read its README for exact licensing and limitations. It is not PitchBook material, not a representative middle-market sample and not fully judged. Rich fields include more factual input than sparse descriptions.

The controlled set is copied from the previous benchmark's `controlled-v1` source (seed 20261002) and converted into the common corpus/queries/qrels schema without relabeling. `data/controlled-source-original/` retains generation metadata, attribute records and hard-negative rationales. It is fully defined as a synthetic screening problem but cannot establish production ranking quality. The seven-query diagnostic set is generated by `scripts/build_datasets.py`; it varies evidence position and profile length and keeps unknowns distinct from negative labels.

SciFact is an unchanged BEIR test split converted to the same schema. The source ZIP SHA-256 is pinned in `scripts/prepare_scifact.py`, and the exact imported files plus attribution are available as the `beir-scifact-test.zip` GitHub Release asset. The source is [BEIR](https://github.com/beir-cellar/beir); the original SciFact corpus and test labels use the licenses listed in the packaged `ATTRIBUTION.md`. The VDI downloads the tested archive from GitHub only. This is scientific claim retrieval, not company screening.

Every dataset has `dataset.json` with source, license and SHA-256 values for the corpus, queries and qrels. Candidate manifests record the dataset digest, text representation, retriever parameters and ordered IDs. `reranker-bench validate-dataset <path>` checks IDs, relevance values and file structure. The source and converted files are retained so reviewers can trace each transformation.

For licensed company data later, use a private dataset path in the same schema (`corpus.jsonl`, `queries.jsonl`, `qrels.tsv`, `dataset.json`) and export ordered candidate lists. Include independently adjudicated labels for direct matches, partials, documented exclusions and unknowns. Do not push licensed records or raw VDI result previews to the public repo.
